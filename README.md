# Jamie's workspace

인테리어·건축 포트폴리오와 현장 사무실용 도구 모음 (by 유재성).

| 주소 | 내용 |
|---|---|
| `/` | 첫 화면 (포트폴리오 · 도구 목록) |
| `/portfolio/` | 전체 포트폴리오 |
| `/rebar/` | 벽체 철근 산정 (H 앵커 · V U바, 배치도 · 3D) |
| `/eps2png/` | EPS·PDF 투명 PNG 변환기 |
| `/scaf/` | 비계 계획서 작성기 → PPT 저장 · 인쇄 |
| `/shor/` | 동바리 계획서 작성기 → PPT 저장 · 인쇄 |
| `/formwork/` | 거푸집 해체 계획서 작성기 → 엑셀 저장 · 인쇄 |
| `/sign/` | Ink Sign 서명 패드 → 투명 PNG · JPG 저장 |

## 계획서 작성기
- 각 폴더의 `d/` 안에 기본 도면 그림과 `manifest.json`(동·층·종류 목록)이 있습니다.
- 처음 열 때 기본 도면을 내려받아 브라우저(IndexedDB)에 저장합니다. 이후에는 저장된 도면을 씁니다.
- 작성기에서 직접 올린 PDF는 쪽마다 제목을 읽어 동·층·종류를 자동으로 나눠 같은 브라우저에 저장됩니다.
- 기본 도면을 바꾸려면 `d/` 의 그림과 `manifest.json` 을 고치고 `version` 값을 바꾸세요. 다음 접속 때 새 도면으로 갱신됩니다.

## 처리 위치
모든 도구는 브라우저 안에서만 동작하고 입력값·파일을 서버로 보내지 않습니다.
